How it works

1

Paste your link

Copy any web address and paste it in the box. If you leave out “https://”, we’ll add it for you.

2

Customize

Pick a color and an error-correction level. Higher levels stay scannable even if the code is slightly damaged.

3

Scan or save

Point your phone camera at the code to test it, then save the image to print or share.

Tips for a great scan

  • Keep strong contrast. Dark code on a light background scans best, so we always use a white backdrop.
  • Print it big enough. Aim for at least 2 × 2 cm (about 1 inch) for reliable scanning.
  • Shorter links are simpler. Fewer characters make a cleaner, easier-to-scan code.
  • Always test it. Scan with your phone before printing or publishing.
